# HelpMap-Project
HelpMap is a project that is meant to help people in need by showing places that they can get free food, health clinic, shelters, clothes. It is also possible for people to add a location with its name and address and what category it is.  At the very bottom it also has some websites that can be of help as well.


How to start this Project:
Import all of the libraries in the main and download all of the required software such as streamlit, folium, and streamlit folium.
you then save the Main file file.txt onto your computer. 
You then want to go into the terminal for the main file and type in streamlit run HelpMap_main.py
this will then run the code and open the website onto google, where you can then see the website.
